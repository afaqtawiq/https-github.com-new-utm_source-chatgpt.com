# جهاز العمل لوكيل آفاق طويق

برنامج صغير يعمل على كمبيوتر العمل (ويندوز). يفتح نافذة Chrome خاصة به، وتسجل أنت الدخول فيها إلى فسح بنفسك.
البرنامج يستلم المهام المعتمدة من النظام، ينفذها، ويرسل كل خطوة مع صورة، ويتحقق من الملفات قبل رفعها.

## التثبيت (مرة واحدة)
1. ثبّت Python 3.12 من python.org (اختر Add to PATH).
2. انسخ مجلد `desktop-runner` إلى الكمبيوتر، وافتح موجه الأوامر داخله ثم نفّذ:
   ```
   pip install -r requirements.txt
   python -m playwright install chromium
   ```
3. من صفحة النظام `/agent-runner` اضغط «إضافة جهاز وإنشاء رمز» وانسخ الرمز (يظهر مرة واحدة).
4. شغّل: `python afaq_runner.py` وألصق الرمز عند الطلب. يُحفظ في ملف إعدادات الجهاز فقط، لا في الكود.

## الأمان
- يفتح فقط المواقع المسموحة (فسح، الزكاة والجمارك، نظام آفاق).
- لا يكتب كلمات مرور ولا رموز تحقق، ولا يحفظها. تسجيل الدخول منك في نافذته.
- المهام الحالية قراءة وتنزيل فقط: لا دفع، لا حذف، لا إرسال بيانات، لا تغيير إعدادات.
- الإيقاف: من واتساب «أوقف المهمة N» أو زر الإيقاف في الصفحة، أو Ctrl+C في نافذة البرنامج.
- الملفات تُحفظ في `المستندات\AfaqRunner\task-N` وتُرفع للنظام بعد التحقق أنها تفتح.
