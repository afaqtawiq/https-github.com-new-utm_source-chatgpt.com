# جهاز العمل لوكيل آفاق طويق

برنامج على كمبيوتر العمل (ويندوز) يفتح نافذة متصفح خاصة به (ملف تعريف منفصل)، وتسجّل أنت الدخول فيها بنفسك.
يستلم المهام المعتمدة من النظام، ينفذها، يسجل كل خطوة ونتيجتها، ويتحقق من الملفات قبل إعلان النجاح.

## الأمان
- رمز الجهاز يُحفظ في «مدير بيانات الاعتماد» في ويندوز (Credential Manager)، لا في ملف ولا في الكود. لحذفه: `python afaq_runner.py --reset`. لتغييره أو إلغائه: من صفحة `/agent-runner`.
- يفتح فقط المواقع المسموحة (https). أي تحويل أو نافذة منبثقة أو تنزيل إلى موقع غير مسموح يُمنع ويوقف المهمة.
- لا يكتب كلمات مرور أو رموز تحقق أو بيانات بطاقات، ولا يصور صفحات تسجيل الدخول، ولا يصدّر الكوكيز.
- إرسال النماذج والدفع والحذف وإرسال البيانات: يطلب موافقتك على كل عملية عبر واتساب («نفذ» + رمز) أو زر في الصفحة؛ بدون موافقة خلال 15 دقيقة تُرفض.
- الإيقاف: «أوقف المهمة N» في واتساب، أو زر الإيقاف في الصفحة، أو Ctrl+C. يتوقف أثناء التنفيذ.
- لحماية الجلسة المحفوظة: استخدم حساب ويندوز مخصص للبرنامج بكلمة مرور، وفعّل قفل الشاشة. ملف المتصفح في `%LOCALAPPDATA%\AfaqRunner` ولا يقرأه غير هذا الحساب.

## التثبيت للتجربة (بعد موافقتك)
1. ثبّت Python 3.12 من python.org (Add to PATH).
2. داخل مجلد `desktop-runner`:
   ```
   pip install -r requirements.txt
   python -m playwright install chromium
   ```
3. من `/agent-runner` اضغط «إضافة جهاز وإنشاء رمز» وانسخ الرمز.
4. شغّل `python afaq_runner.py` وألصق الرمز (لا يظهر أثناء الكتابة).
5. اكتب للوكيل: «شغّل مهمة تجريبية». النتيجة: ملف PDF تجريبي نزل وتم التحقق أنه يفتح.
6. لإزالة كل شيء: `python afaq_runner.py --reset`، ألغِ الجهاز من الصفحة، واحذف مجلد `%LOCALAPPDATA%\AfaqRunner`.
